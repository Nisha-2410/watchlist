## License and exclusions

All four supplied repositories declare MIT licences. `trading-bb` can use AGPL OpenBB as an installed dependency; it must not be copied or made a product dependency without a licence review. We reject trading execution, price prediction, portfolio/optimization, social sentiment scoring, alerts/push, AI narratives, generic screeners, and dashboards because the PRD forbids or does not require them.

## Practical run status

The frontend reference has package manifests and lockfile but no installed `node_modules`; backend references depend on external credentials/services (FastAPI, Redis/Kafka/Postgres/Celery) and were inspected statically. Running their production stacks is intentionally deferred until the target product architecture and credentials are selected; this is not evidence that their capabilities were assumed rather than inspected.
